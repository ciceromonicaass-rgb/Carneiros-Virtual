🧩 Desafio 3: Normalize a Tabela

A tabela abaixo tem problemas. Normalize-a até a 3FN identificando as formas normais.

PEDIDOS (id, cliente_nome, cliente_cidade, cliente_cep, produto_nome, produto_preco, qtd, data)

Preencha o nome de cada Forma Normal:

1FN: Garantir que cada campo tenha valor (não listas)
2FN: Eliminar dependência (separar produtos)
3FN: Eliminar dependência (separar cliente/cidade/cep)
Resultado: tabelas normalizadas

💡 Dicas

  • 1FN: cada célula deve ter um valor atômico (unico)
  • 2FN: eliminar dependência parcial (atributos que dependem de parte da chave)
  • 3FN: eliminar dependência transitiva (cidade depende de cep, não de id)
  • Resultado: CLIENTE, PRODUTO, PEDIDO, ITEM_PEDIDO = 4 tabelas

🧩 Desafio 4: CREATE TABLE em SQL

Complete o comando SQL para criar a tabela de alunos com chave primária e constraints.

CREATE TABLE (
  id INT KEY,
  nome VARCHAR(100) ,
  email VARCHAR(100) ,
  turma_id INT,
  FOREIGN KEY (turma_id) REFERENCES (id)
);

💡 Dicas

  • Nome da tabela: alunos (plural, minuscula)
  • Chave primária: PRIMARY
  • Não nulo: NOT NULL
  • Único: UNIQUE
  • Tabela referenciada pela FK: turmas
