Q1Qual comando SQL e utilizado para remover uma tabela inteira e sua estrutura do banco de dados?
Alternativas:
A) DELETE TABLE
B) REMOVE TABLE
C) DROP TABLE ✅
D) ERASE TABLE
RESPOSTA CORRETA: C)
DROP TABLE
Explicacao: DROP TABLE remove a tabela inteira, incluindo estrutura e dados. DELETE remove apenas linhas, mantendo a estrutura.
Q2Qual das seguintes memorias e volatil e perde seus dados ao desligar o computador?
Alternativas:
A) ROM
B) SSD
C) RAM ✅
D) HD
RESPOSTA CORRETA: C)
RAM
Explicacao: RAM e volatil: perde tudo ao desligar. ROM, SSD e HD sao nao volateis (guardam dados sem energia).
Q3Qual protocolo da camada de aplicacao e responsavel pela atribuicao dinamica de enderecos IP?
Alternativas:
A) DNS
B) DHCP ✅
C) HTTP
D) FTP
RESPOSTA CORRETA: B)
DHCP
Explicacao: DHCP atribui IPs automaticamente na rede. DNS resolve nomes em IP, HTTP e web, FTP e transferencia de arquivos.
Q4Em estrutura de dados, qual e a principal caracteristica de uma PILHA (Stack)?
Alternativas:
A) FIFO (First In, First Out)
B) LIFO (Last In, First Out) ✅
C) Random Access
D) Priority Access
RESPOSTA CORRETA: B)
LIFO (Last In, First Out)
Explicacao: Pilha funciona como LIFO: o ultimo elemento inserido e o primeiro a sair. Como pilha de pratos.
Q5Qual e a mascara de rede padrao em formato CIDR para uma rede de Classe C (/24)?
Alternativas:
A) 255.0.0.0
B) 255.255.0.0
C) 255.255.255.0 ✅
D) 255.255.255.255
RESPOSTA CORRETA: C)
255.255.255.0
Explicacao: /24 = 255.255.255.0 (Classe C, 254 hosts). /8 = Classe A, /16 = Classe B.
Q6No sistema operacional Linux, qual comando altera as permissoes de acesso de arquivos?
Alternativas:
A) chown
B) chmod ✅
C) chgrp
D) ls -l
RESPOSTA CORRETA: B)
chmod
Explicacao: chmod altera permissoes (leitura/escrita/execucao). chown muda o dono, chgrp muda o grupo, ls -l apenas lista.
Q7Qual porta padrao e utilizada pelo protocolo seguro HTTPS?
Alternativas:
A) 80
B) 21
C) 443 ✅
D) 22
RESPOSTA CORRETA: C)
443
Explicacao: HTTPS usa porta 443. HTTP usa 80, FTP usa 21, SSH usa 22. HTTPS e HTTP criptografado (SSL/TLS).
Q8Qual componente executa o ciclo de busca, decodificacao e execucao de instrucoes?
Alternativas:
A) Placa-Mae
B) CPU (Processador) ✅
C) Chipset Ponte Sul
D) Memoria Cache
RESPOSTA CORRETA: B)
CPU (Processador)
Explicacao: A CPU executa: busca a instrucao na memoria, decodifica e executa. E o cerebro do computador.
Q9Na POO, a capacidade de um metodo ter diferentes formas de execucao chama-se:
Alternativas:
A) Encapsulamento
B) Heranca
C) Polimorfismo ✅
D) Abstracao
RESPOSTA CORRETA: C)
Polimorfismo
Explicacao: Polimorfismo = 'muitas formas'. Mesmo metodo, comportamentos diferentes por objeto. Encapsulamento esconde dados, heranca reutiliza codigo.
Q10O que significa a sigla SSD no contexto de dispositivos de armazenamento de dados?
Alternativas:
A) Solid State Drive ✅
B) System Storage Device
C) Secure System Disk
D) Serial State Disk
RESPOSTA CORRETA: A)
Solid State Drive
Explicacao: SSD = Solid State Drive. Usa memoria flash sem partes moveis, muito mais rapido que HD tradicional.
Q11Qual das alternativas representa um endereco IP publico valido na Internet?
Alternativas:
A) 10.0.0.1
B) 172.16.0.1
C) 192.168.1.1
D) 200.150.10.5 ✅
RESPOSTA CORRETA: D)
200.150.10.5
Explicacao: 200.150.10.5 e publico. 10.x, 172.16-31.x e 192.168.x sao privados (reservados para redes internas).
Q12Em bancos de dados relacionais, o que define uma Chave Estrangeira (Foreign Key)?
Alternativas:
A) Um identificador unico e exclusivo de uma linha
B) Um campo que estabelece vinculo com a PK de outra tabela ✅
C) Um indice automatico criado para acelerar buscas
D) Um campo de preenchimento obrigatoriamente numerico

Um campo que estabelece vinculo com a PK de outra tabela

Q15Qual topologia de rede fisica utiliza um ponto central de conexao (como um Switch)?
Alternativas:
A) Barramento (Bus)
B) Anel (Ring)
C) Estrela (Star) ✅
D) Malha (Mesh)
RESPOSTA CORRETA: C)
Estrela (Star)
Explicacao: Topologia Estrela: todos se conectam a um ponto central (switch). Se um cabo quebra, so aquele PC cai. Barramento usa cabo unico, Anel forma circulo.
Q16Na arquitetura de Von Neumann, qual unidade realiza operacoes aritmeticas e logicas?
Alternativas:
A) UC (Unidade de Controle)
B) ULA (Unidade Logica e Aritmetica) ✅
C) Registradores
D) Barramento de Dados
RESPOSTA CORRETA: B)
ULA (Unidade Logica e Aritmetica)
Explicacao: A ULA executa somas, subtracoes, comparacoes (AND, OR, NOT). A UC apenas coordena, Registradores armazenam dados temporarios.
Q17No Linux, qual comando exibe o diretorio de trabalho atual do usuario no terminal?
Alternativas:
A) dir
B) cd
C) pwd ✅
D) path
RESPOSTA CORRETA: C)
pwd
Explicacao: pwd (Print Working Directory) mostra o caminho completo do diretorio atual. dir lista arquivos, cd muda de diretorio.
Q18Qual protocolo da camada de transporte garante a entrega ordenada e confiavel de dados?
Alternativas:
A) UDP
B) TCP ✅
C) IP
D) ICMP
RESPOSTA CORRETA: B)
TCP
Explicacao: TCP garante entrega confiavel, ordenada e sem perda. UDP e rapido mas nao garante. IP e camada de rede, ICMP e diagnostico (ping).
