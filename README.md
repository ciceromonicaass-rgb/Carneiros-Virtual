# Carneiros Virtual - Plataforma Educacional Offline

## Sistemas Disponíveis

### BT-RAMB (Saberes Digitais)
Plataforma educacional alinhada à BNCC e BNCC Computação - do Infantil ao 9º ano.

- **616 planos de aula** com BNCC
- **830 questões** com correção automática
- **60 atividades BNCC Computação** (plugadas e desplugadas)
- **40 artigos Mundo Digital** (Segurança, Cidadania, Desinformação, Ética)
- **11 trilhas gamificadas** com 70 níveis
- **11 disciplinas** cobertas (Matemática, Português, Ciências, História, Geografia, Arte, Ed. Física, Inglês, Ensino Religioso, Computação, Informática)

### Portal Carneiros Virtual
Hub com 54 sistemas educacionais offline em um único arquivo HTML.

## Como Usar
1. Baixe o arquivo HTML
2. Abra no navegador (Chrome, Firefox, Edge)
3. Funciona 100% offline - sem internet necessária

## Padrão Técnico
- Single-file HTML (sem dependências externas)
- Armazenamento em localStorage
